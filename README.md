# Fintech App
Fintech mobile application focused on currency trading,
designed to provide a secure and reliable user experience.

The app emphasizes:
- Secure authentication and user data protection
- Smooth and clear user flows suitable for financial applications
- Clean UI/UX built around trust and usability
- Scalable architecture following best practices

This project was developed as part of a mentorship program
under the guidance of Omar Ahmed,
with a focus on applying real-world fintech concepts and production-level standards.
